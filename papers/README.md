# 📬 papers/ — 논문 인박스

`topics.yaml`에 적어 둔 연구 주제로 **매주 자동 수집된 새 논문**이 여기 쌓인다.

| 파일 | 무엇 |
|---|---|
| `inbox.md` | 이번 주 새 논문 목록 (매주 덮어씀) |
| `seen.json` | 이미 본 논문 기록 — 같은 논문이 다시 안 뜨게 (자동) |
| `READING_STATUS.md` | 지금 어느 논문 어디까지 — 논문 세션의 진입점 |
| `<slug>/` | **논문 한 편의 저장소** (아래) |

## 논문 하나를 읽기 시작하면 — `papers/<slug>/`

한 편을 여러 세션에 걸쳐 관통한다. 세션이 끝날 때마다 CI가 아래를 채운다.

| 경로 | 무엇 |
|---|---|
| `sessions/YYYY-MM-DD-<섹션>.md` | 세션 원문 — **내가 한 말 그대로**. 실패하지 않는 경로 |
| `paper.md` | 정제본 — **검증된 이해만**. 설명하지 못한 것은 오지 않는다 |
| `annotations.md` | 인용 + 내 코멘트 (쌓인다) |
| `parking-lot.md` | 미뤄 둔 선수지식 — 별도 학습 세션의 재료. 해소되면 `- [x]` |
| `meta.yaml` | 서지 + **현재 이해 단계**(미이해 / 부분 / 기능적 / 비판적) |
| `artifacts/` | 세션에서 만든 시각 자료 — 다음 세션 복습용 |

읽기 대본은 [`runner/paper-mode.md`](../runner/paper-mode.md)에 있다.

**쓰는 법**: 학습 세션에서 *"이번 주 새 논문 같이 보자"* 라고 하면 러너가 여기서 골라 준다.
다 읽지 말 것 — 제목·초록만 훑고 **한 편만 골라** 깊게 보는 편이 낫다.

**지금 당장 돌려보려면**: repo → Actions → **paper-scan** → Run workflow
