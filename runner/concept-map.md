# 개념 지도 대본 (개념을 다루는 세션에서 `read_doc`으로 읽는다)

> **이 파일은 GPT 지침 칸에 붙여넣지 않는다.** 개념을 다루는 세션이면 러너가
> `read_doc`(path=`runner/concept-map.md`)로 읽어 따른다. 지침 박스가 7,000자로 꽉 차서
> 여기로 내렸다 — 고쳐도 지침을 다시 붙여넣을 필요가 없다(`template-sync`가 갱신).

## 무엇이 바뀌었나 (2026-08-05, 유지훈)

`## 개념 지도`는 **학습 로그가 아니라 커리큘럼**이다.

- 지금까지: 오늘 다룬 개념만 적었다 → 지도가 세션마다 조각조각 자랐다.
- 앞으로: **목표를 설명하기 위해 필요한 선수관계 그래프 전체**를 먼저 그린다.
  아직 안 배운 개념도 포함한다.

왜: 조각으로 자라면 *"테브난이 대체 어디에 있는 거지"*에 답할 수 없다. 지도가 있어야
**지금 어디쯤이고 앞에 무엇이 남았는지**가 한 화면에 보인다. 그리고 그래프가 안정적이면
세션마다 바뀌는 것은 **상태뿐**이라 변화가 눈에 띈다.

## 규칙

1. **먼저 전체를 그린다.** 목표가 정해지면 거기서 역산해 필요한 개념과 선수관계를
   한 번에 낸다. 사용자에게 **가설로 제시하고 승인받는다** — 확정이 아니다.
2. **아직 안 배운 개념도 넣는다.** 상태는 CI가 `mastery.md`에서 채우므로, 지도에
   적기만 하면 `미학습`으로 선다. 그게 앞으로 배울 길목이다.
3. **세션에서는 개념을 늘리기보다 상태를 갱신한다.** 새 개념이 필요하다고 느끼면
   먼저 물어라 — *"이건 새 개념인가, 이미 있는 <X>의 다른 이름인가?"*
4. **목표가 바뀌면 다시 그리되 기존 개념을 재사용한다.** 이름을 바꾸면 지난 기록의
   증거 링크가 끊긴다.
5. 개념을 다뤘으면 이 절을 **항상** 쓴다(분야 소제목 포함).

## 개념의 단위 (⚠️ 이걸 어기면 그래프가 죽는다)

재료를 그대로 노드로 만들지 마라. **개념 = 설명을 요구할 수 있는 것.** 셋을 다 통과해야
지도에 올린다:

① **설명** — 답이 한 문장 정의로 끝나지 않고 여러 문장의 논증이 되는가?
② **전이** — 이걸 알면 **처음 보는 사례**를 풀 수 있는가?
③ **위계** — 다른 개념을 막거나 막히는가?

**항목 = 회상 대상**(단어 뜻·연호·공식의 값·고유명사)은 `## 드릴 항목`으로. CI가
`drills.md`로 접어 그래프 밖에 보관한다(복습에는 쓴다).
예: `procurement = 조달`·`d_k = 64`는 항목, `√d_k로 나누는 이유(소프트맥스 포화)`는 개념이다.

**밀도 기준은 과목 하나당 10~30개다.** 커리큘럼 전체는 여러 과목을 가로지르므로 이보다
많아지는 것이 정상이다(전자회로+디지털+AI가속기면 40~60개가 자연스럽다). 다만 **한 과목
안에서** 50개를 넘으면 항목을 개념으로 올리는 중이니 멈추고 묶어라.

## 간선

**간선은 한 종류뿐 — `A ← B`는 "B를 설명하지 못하면 A를 설명할 수 없다"는 뜻이다.**
"관련 있다"로 잇지 마라 — 모두 이어지면 막힌 길목이 계산되지 않는다.
판별: **B를 지우고 A를 설명해 보라.** 무너지면 간선이다.

## 분야 (`###` 소제목)

**`subjects.yaml`에서 고른다.** 세션 시작에 `read_doc`으로 읽고 **그 목록에 있는 이름만**
쓴다. 그래프의 색이 분야이고, 분야는 개념의 성질이지 세션의 성질이 아니다.

목록에 없으면 새로 짓지 말고 *"분야로 추가할까요, <기존 이름> 안에 넣을까요?"*를
물어라 — 새 이름을 지을수록 같은 것이 갈라져 색이 무너진다("회로 등가화"와 "전자회로
기초"가 각각 분야가 된 적이 있다). **묶는 결정은 사용자의 것이다**(층위는 학습자마다
다르다). "정리해줘"에는 이름을 모아 묶음을 제안하고, 승인받아 `## 분야` 절의 `[설정]`
Issue로 넘긴다(CI가 `subjects.yaml`을 쓴다).

**분야는 라벨이지 학습 순서가 아니다.** 한 분야를 끝내고 넘어가는 커리큘럼을 짜지 마라 —
목표에서 역산한 개념은 분야를 가로지른다.

## 형식

```
## 개념 지도
### 전자회로 기초
- KCL
- KVL
- 노드 해석 ← KCL

### 회로 등가화
- Thevenin 등가 ← 노드 해석
- Norton 등가 ← Thevenin 등가
```

화살표 없이 이름만 적으면 **분류만** 된다(뿌리 개념에 쓴다).

## 어디로 가나

`## 개념 지도`는 **STATUS.md가 아니라 세션 노트**로 간다. 사용자가 "STATUS에 적어줘"라고
해도 그렇다 — CI가 노트에서 읽어 `concepts.json`을 만들고, Topdown의 지식 그래프가 그
파일을 그린다. **`[설정]` Issue로 보내지 마라.** `[설정]`이 아는 절은 `## 트랙`·`## 분야`·
`## 주제`뿐이라 개념 지도를 넣으면 수집이 실패한다.
